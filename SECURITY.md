# Политика безопасности

## Сообщение об уязвимости

Не публикуйте сведения об уязвимости в открытых issues. Сообщите о ней приватно: вкладка **Security** репозитория → **Report a vulnerability**. Укажите версию (коммит), шаги воспроизведения и возможные последствия.

## Поддерживаемые версии

Исправления выпускаются только для актуального состояния ветки `main`.
